TextMate

Выберите режим обработки текста. Можно использовать локальный или облачный AI либо полностью офлайн-проверку русского текста без AI.

Локальный режим

Простые действия идут через быструю модель, редактирование и перевод — через более сильную.

Быстраяqwen3:0.6b
Качественнаяqwen3:1.7b
Установите Ollama и один раз выполните:
ollama pull qwen3:0.6b
ollama pull qwen3:1.7b

Если 1.7b не установлена, расширение автоматически использует 0.6b.

Исправление текста без AI

Текст не отправляется в AI или на сервер обработки. При первом использовании TextMate скачивает открытый русский словарь LibreOffice (~4 МБ) и сохраняет его локально в браузере.

В этом режиме доступно только действие «Редактировать».

Используется русский Hunspell-словарь LibreOffice: неизвестные слова сверяются со словарём, а для уверенных опечаток подбирается ближайшее написание. Также проверяются пробелы, базовая пунктуация, регистр и повторы слов.

Сложную стилистику, смысловые ошибки и неоднозначные правила этот режим намеренно не исправляет.

Подходит для OpenAI-compatible сервисов и будущего собственного сервера.

Поддерживаемые редакторы

Есть отдельные адаптеры для Google Docs/Sheets, Word Online, Notion, Gmail и Telegram Web. На остальных сайтах используется универсальный адаптер.

Google Docs использует собственную модель документа: если безопасная замена выделения недоступна, расширение покажет исправленный результат для копирования, не меняя документ напрямую.

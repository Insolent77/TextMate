Редактор текста с ИИ — v0.5.0

Что нового:
- Автопроверки при вводе НЕТ. Все действия запускаются только пользователем.
- Два режима: локальный Ollama и облачный.
- Провайдеры: Ollama, Gemini API, OpenAI-compatible API / собственный сервер.
- Гибрид Ollama: qwen3:0.6b для быстрых преобразований; qwen3:1.7b для редактирования и перевода.
- Если qwen3:1.7b нет, используется qwen3:0.6b.
- Кэш одинаковых запросов на 30 минут.
- Обе локальные модели прогреваются в фоне и не блокируют интерфейс.
- Отдельные адаптеры: Google Docs, Google Sheets, Word Online, Notion, Gmail, Telegram Web.
- Для остальных сайтов используется универсальный адаптер.
- Исправлена безопасная отправка сообщений после обновления расширения.
- Background разбит на providers/cache/actions/context-menu/logger.
- Content-часть получила отдельные runtime и adapters.

Установка:
1. Распакуйте архив.
2. Откройте chrome://extensions.
3. Включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение» и выберите папку chrome-ai-corrector.
5. После обновления расширения обновите уже открытые вкладки через F5.

Локальный режим:
ollama pull qwen3:0.6b
ollama pull qwen3:1.7b

Google Docs:
Редактор имеет собственную внутреннюю модель документа. Расширение пытается использовать безопасную команду вставки. Если прямую замену выполнить нельзя, документ не изменяется — результат можно скопировать вручную.


V0.5.1
- Исправлены пустые ответы для Упростить/Сократить/Вежливее/Официальнее/Переформулировать.
- Быстрые действия больше не требуют JSON-schema от qwen3:0.6b.
- Уменьшено число генерируемых токенов для ускорения.
- Формат Ollama отправляется только когда он действительно нужен.
- Добавлен резервный разбор поля response.


V0.5.2
- Исправлена общая ошибка Ollama-провайдера после рефакторинга v0.5.x.
- Действия передавали system/user, а Ollama ожидала messages[].
- Теперь Ollama-провайдер автоматически преобразует system/user в messages.
- Добавлена проверка, что в Ollama действительно передан текст.
- Пустой ответ Ollama теперь обрабатывается явно.


V0.6.0
- Клик по иконке TextMate теперь открывает компактное popup-окно.
- В popup доступны режим работы, провайдер, текущие модели, быстрые действия,
  автокопирование и проверка подключения.
- Кнопка «Расширенные настройки» открывает прежнюю полную страницу options.html.
- Если меняете быстрые действия на уже открытой странице, обновите её через F5.
